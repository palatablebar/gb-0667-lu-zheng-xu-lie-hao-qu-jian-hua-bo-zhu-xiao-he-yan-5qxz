# 数据定义

区间首末号为闭区间，内部转为半开区间。序列号使用Python整数运算，对外按文本输出，大整数不经过浮点。事件时间必须带偏移且先转UTC；同刻按事件号排序。事件号冲突全部隔离，相同事件只采信一条。注销不可撤销，重复签发不能恢复证书。全局签发=各持有人可用+已注销；划拨只是持有人变化。

- 空串、`-`、`N/A`、`NULL`、`未知`是缺失哨兵，不作为零。
- 原始批号、事件号均为文本，保留前导零。
- CSV支持UTF-8 BOM和GB18030，必须有完整表头，支持列顺序调整。
- 文件最大2MB、10000条记录；读取时逐记录校验，计算阶段保留受此上限约束的数据。
- 空文件、全空行、仅表头分别标记EMPTY_FILE、BLANK_ONLY、HEADER_ONLY。
- 多余列隔离；非法引号导致整次请求失败，不保存半批。
- 幂等键=输入字节摘要+规则版本+参数；内容完全相同复用批次。
- 复核采用整数版本比较，旧版本返回409。

## 跨版本补正（2026.11.2）

各月绿证批次到达后，补正版可能把已注销序号划回可用池。系统按以下规则裁决正式持仓，月结采用最新补正生效结果，但注销事实不可复活。

- **版本梯**：同`event_id`的记录按`version`归梯并降序。业务指纹排除`note`列；同指纹重复只采信一条（`DUPLICATE`），同版本号异值仅隔离该版本组（`CONFLICT`），其它干净版本保留。
- **全局重放顺序**：所有干净版本按（UTC时间, 版本号, 事件号）排序，补正在其自身到达时刻生效，不溯及改写历史事件；同刻版本号高者后到。
- **试换版与回退**：套用更高版本前先回退同事件当前生效版的名义账；新版本业务校验失败（OVERLAP/NOT_OWNED/RETIRED/OWNER）则恢复旧版，旧版继续生效并保留来源行与原值（`SUPERSEDED`留痕，失败标`VERSION_FALLBACK`）。
- **注销墙（retirement wall）**：所有曾生效版本中合法注销区间的并集，只增不减，天然幂等——同一补正重试不会重复占用或重复注销。
- **正式持仓裁决**：名义持仓=最新补正重放结果；正式可用=名义持仓−注销墙，已注销=注销墙∩签发。补正把墙内序号划回可用池时，名义划拨被`WALL_BLOCKED`拦截，正式持仓不复活该序号；补正缩小注销范围时，墙仍保留旧版较大事实。
- **守恒**：逐批号区间满足 签发=可用+已注销（已划拨为可用池中外部持有人占用，含入可用）；全局 签发=正式可用+墙注销。
- 新增原因码：`CORRECTION_REJECTED`、`VERSION_FALLBACK`、`WALL_BLOCKED`、`SUPERSEDED`。

序列号最多40位，持仓和注销区间按签发宽度保留前导零。
